# Fotoğraf Ekleme Rehberi

Elinizdeki çekici ve kurtarma operasyonu fotoğraflarını bu klasöre (`images/`) ekleyebilirsiniz.

### Önerilen Görsel İsimleri:
- `galeri-1.jpg`: Ana sayfa kayar kasa operasyonu
- `galeri-2.jpg`: Otoyol gece/gündüz çekim fotoğrafı
- `galeri-3.jpg`: Aparatlı çekim fotoğrafı
- `galeri-4.jpg`: Motosiklet taşıma fotoğrafı
- `[bolge-slug].jpg`: Örneğin `tuzla-oto-cekici.jpg`, `gebze-oto-cekici.jpg` (Bölge sayfalarındaki ilgili fotoğraf yuvasında otomatik görüntülenir).
